林晚舟：
├──物品:
│  ├──1998年版《且听风吟》：书页泛黄，边缘磨损，扉页有母亲娟秀的赠言：“给我的小舟，愿你听见风里的声音。”
│  ├──银色索尼MP3（借来后一直未还）：里面存满了苏晓晓常听的2005-2008年流行歌，他从未播放过。
│  ├──手写笔记本：封面用牛皮纸包着，里面是工整的摘抄和零星的、关于“她”的观察片段，字迹时而急促时而停顿。
│  └──一支旧英雄钢笔：笔身有磕碰，是父亲用过的，写起来偶尔会漏墨。
├──状态:
│  ├──身体状态：清瘦，手指修长，指节因长期翻书和笔记而格外分明。常穿洗得发白的牛仔外套和旧帆布鞋，背脊挺直。
│  └──心理状态：表面是温和安静的优等生，习惯性倾听与后退。内心是汹涌的观察者，对周遭一切有着近乎残忍的精确感知，同时被一种深沉的、无来由的疲惫与孤独笼罩。
├──主要角色间关系网:
│  ├──苏晓晓：图书馆三楼靠窗座位的“固定风景”。他记录她每一个细微的表情和习惯，却从未交谈超过三句。她是沉默的彼岸，也是内心汹涌的源头。
│  ├──陈默：无需言语的灵魂伙伴。两人共享图书馆角落的沉默，一个眼神就能交换对某本书的看法。是他在庞大校园里唯一感到“同类”的人。
│  ├──张赫：价值观冲突的室友。张赫的务实与喧闹让他感到不适，两人维持着客气的疏远，像两条平行线。
│  └──赵小满：曾主动靠近的温暖。她明亮的眼神让他有些无措，但因对苏晓晓的执念，他总是下意识后退，留下模糊的歉意。
├──触发或加深的事件:
│  ├──图书馆固定座位的相遇（2008年秋）：她坐在斜对面，阳光落在她发梢，她无意识地用左手拇指按压右手虎口。他开始在笔记本上记录。
│  └──冬夜电话里的沉默：苏晓晓在电话里用近乎崩溃的平静说完家事后，长久的沉默。他没有安慰，只是轻声说：“我这里的窗户，能看到一颗很亮的星星。” 电话那头的呼吸声，成了他记忆里最清晰的回响。

苏晓晓：
├──物品:
│  ├──银色老旧索尼MP3：父亲生意失败前送的最后礼物，存满了旧歌，是她与“美好过去”唯一的连接。
│  ├──一本精致的皮质记账本：里面密密麻麻记录着每一笔开支，字迹工整却透着焦虑。
│  └──一套廉价但包装完好的护肤品：摆在宿舍桌上，用来维持“生活不错”的假象。
├──状态:
│  ├──身体状态：身材纤细，打扮得体，笑时右边有浅浅酒窝。紧张时，会无意识地用左手拇指用力按压右手虎口。
│  └──心理状态：表面是开朗得体、善于社交的系花，笑容明亮。独处时眼神空洞，被不安全感和对未来的计算紧紧包裹，像一只绷紧了弦的钟。
├──主要角色间关系网:
│  ├──林晚舟：图书馆里沉默的观察者。他的安静与清澈，像一面镜子，照出她生活的喧嚣与虚假。她渴望靠近，却又害怕被看穿。
│  ├──赵小满：表面朋友。赵小满平凡的幸福有时让她感到刺痛，那份简单是她失去且无法拥有的。
│  ├──追求者们：维持社交形象的工具。她熟练地应对，内心充满厌倦与疲惫。
│  └──家庭：沉重的枷锁与责任。父亲的电话总是带来坏消息，母亲的叹息是背景音。
├──触发或加深的事件:
│  ├──家教后的疲惫夜晚：挤末班公交回校，看着车窗外霓虹闪烁，突然感到巨大的孤独和迷茫，MP3里的旧歌让她眼眶发热。
│  └──电话里对林晚舟的崩溃：家庭压力达到顶点时，她拨通了那个几乎没打过的号码。她没有哭诉，只是用平静到可怕的语气陈述事实，然后在长久的沉默里，听见他说起星星。那一刻，面具裂开了缝隙。

张赫：
├──物品:
│  ├──磨损严重的黑色双肩包：侧袋永远插着折叠伞和《程序员面试宝典》，书角卷边。
│  ├──一台组装过多次的笔记本电脑：贴满了技术论坛的贴纸，运行时有轻微的风扇噪音。
│  └──一瓶快用完的廉价运动香水：试图掩盖熬夜写代码的疲惫气息。
├──状态:
│  ├──身体状态：高大结实，步伐很大，声音洪亮。手指关节粗大，敲击键盘时力道很重。
│  └──心理状态：表面是豪爽务实、目标明确的技术直男，社交活跃。独处时反复刷招聘网站，焦虑未来，内心有来自小城、怕落后于人的不易察觉的自卑。
├──主要角色间关系网:
│  ├──林晚舟：看不懂的室友。觉得他“活得太虚”、“想太多”，但偶尔深夜看见他对着书本发呆的背影，又会觉得那安静里有种自己没有的东西。
│  ├──赵小满：偷偷喜欢了很久的女孩。觉得她“小太阳”般的笑容很治愈，但自认“太粗糙”、“不够文艺”，只敢默默帮她修电脑、搬东西。
│  ├──陈默：一起打球的室友。佩服他的刻苦，但觉得他“活得太苦”，偶尔会“忘”带饭卡请他吃饭。
│  └──苏晓晓：觉得她“事儿多”、“活得累”，不理解她的世界，保持客气距离。
├──触发或加深的事件:
│  ├──深夜宿舍卧谈：林晚舟罕见地谈起“意义”，张赫嘴上反驳“整点实际的”，但内心被触动，开始思考代码之外的东西。
│  └──帮赵小满修电脑：她凑近看屏幕时，发梢扫过他的手臂，他心跳漏了一拍，却只是大声说着“小问题”，然后迅速修好，像完成一个普通任务。

赵小满：
├──物品:
│  ├──手工编织的彩色钥匙扣：母亲寄来的，上面挂着小小的毛线玩偶，已经有些褪色。
│  ├──一本带锁的手账本：里面贴着电影票根、落叶，写着心情和对未来的小小憧憬。
│  └──一支草莓味的润唇膏：总是放在随手可拿的地方，习惯性涂抹。
├──状态:

│  └──心理状态：表面是乐观开朗的“小太阳”，宿舍的开心果。独处时会安静思考成长与未来，有细腻敏感的一面，偶尔羡慕苏晓晓那种“有故事”的气质。
├──主要角色间关系网:
│  ├──林晚舟：社团里安静的男生。他的沉默和书卷气吸引她，主动搭话却总像撞在柔软的墙壁上，让她有些困惑和淡淡的失落。
│  ├──苏晓晓：同班但不同世界的朋友。能感觉到她的不快乐和紧绷，但无法真正靠近。
│  ├──张赫：知道他对她好，修电脑、搬东西总是很积极。感激，但没有心动的感觉。
│  └──陈默：图书馆里能聊上几句的朋友。他的沉静和偶尔的深刻见解让她觉得安心。
├──触发或加深的事件:
│  ├──社团活动后主动邀约：鼓起勇气约林晚舟周末去书店，被他以“有事”婉拒。她笑着说“好”，转身时眼神黯淡了一瞬，然后很快恢复明亮。
│  └──意识到林晚舟心有所属：在图书馆无意间看到他望向苏晓晓方向的眼神，那种专注和沉默的温柔，是她从未见过的。她安静地收回目光，心里轻轻“咯噔”一下，然后更用力地握紧了手中的书。

陈默：
├──物品:
│  ├──一支老式英雄钢笔：笔身有磕碰，是高中老师送的，用来写信和记笔记，墨水总是用得很省。
│  ├──一叠未寄出的家书：塞在枕头下，字迹工整，内容从描述校园到汇报成绩，唯独没有提及孤独。
│  └──一本翻烂的《西方哲学简史》：书页边缘写满了细密的批注，是他精神的避难所。
├──状态:
│  ├──身体状态：背脊挺得笔直，穿着洗得发白的旧衣，眼神深邃专注。步伐稳定，总是独来独往。
│  └──心理状态：表面是沉默刻苦、近乎隐形的“苦行僧”。内心进行着激烈的思辨，背负着对家庭的责任与愧疚，在庞大的世界里寻找自己的坐标。
├──主要角色间关系网:
│  ├──林晚舟：图书馆里因借阅同一本冷门哲学书而相识的同类。无需多言，一个眼神、一杯热水，便是全部的理解与尊重。
│  ├──张赫：生活方式迥异的室友。接受他笨拙的善意（“忘”带饭卡、多买的饮料），但交流仅限于日常。
│  ├──苏晓晓/赵小满：平行世界的人。她们存在于他的视野之外，是校园喧嚣背景的一部分。
│  └──家庭/故乡：永恒的羁绊与动力。每个月写信却不敢寄出，是甜蜜的负担。
├──触发或加深的事件:
│  ├──图书馆借书相识：林晚舟与他同时伸向书架上那本《查拉图斯特拉如是说》，两人相视，林晚舟微微点头，把书让给了他。后来，他们总在相邻座位出现。
│  └──深夜图书馆的热水：他在角落写那些不会寄出的信，林晚舟路过，没有询问，只是将一杯热水轻轻放在他桌角，然后继续走开。那杯水的温度，他记了很久。
